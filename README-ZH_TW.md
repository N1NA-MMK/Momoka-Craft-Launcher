Momoka Craft Launcher（簡稱 MCL）是基於 [PCL 社群版](https://github.com/PCL-Community/PCL-CE)（PCL CE）二次開發的版本，主要在視覺與互動體驗上進行調整，未對核心功能做大幅改動。

## 功能特性

- **遊戲管理**：多實例隔離、版本隔離、整合包匯入匯出、存檔管理
- **資源下載**：Mod、整合包、資源包、光影、資料包一鍵下載（CurseForge / Modrinth）
- **帳號系統**：微軟正版登入、離線登入、第三方皮膚站（外掛登入）登入
- **Java 管理**：自動偵測、手動新增、按實例設定
- **主題系統**：可自訂主題色、背景圖片/影片、毛玻璃效果
- **多語言**：簡中、繁中、英語、日語、法語、西班牙語等
- **跨架構**：支援 x64 與 ARM64 原生執行

## 支援平台

| 作業系統 | 支援情況 | 環境要求 |
|---|---|---|
| Windows 10 1809 (17763) 或更高 | ✅ 完整支援 | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 8 - Windows 10 1809 (17763) | ⚠️ 理論能跑，酌情提供社群支援 | [.NET 10 Desktop Runtime](https://get.dot.net/10) |
| Windows 7 或更低版本 | ❌ 不支援 | / |
| macOS / Linux / 其他作業系統 | ⚠️ 僅跨平台開發支援（交叉編譯）| [.NET 10 SDK](https://get.dot.net/10) |

> 始終建議使用最新版本作業系統以獲得最佳體驗。
